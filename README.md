## ✨ Tính Năng Nổi Bật & Công Nghệ

### 🌌 1. Không gian 3D WebGL tương tác (Three.js Engine)
- Render mạng lưới hạt lượng tử 3D WebGL với hệ thống kết nối node ánh sáng neon và chuyển động camera theo tọa độ chuột (**Mouse Parallax 3D**).
- Tại Node 01 (Khang): Tích hợp **Lõi năng lượng nguyên tử 3D Holographic Quantum Reactor** với các vòng xoay Gimbal Gyroscope và khối lập phương công nghệ bay lơ lửng.

### ⏳ 2. Màn hình Khởi động Cyber Preloader
- Hoạt ảnh khởi động màn hình đen sâu với 3 vòng xoay đồng tâm Neon (`#00f2fe`, `#a855f7`, `#10b981`).
- Dòng lệnh Terminal mô phỏng quá trình boot giao thức lượng tử, thanh tiến trình đổ đầy tự động từ `0%` đến `100%` và hiệu ứng mở màn Shutter mượt mà.

### 🎯 3. Cyber Reticle HUD Cursor
- Con trỏ chuột công nghệ cao lập trình thuần SVG + JavaScript, gồm tâm ngắm bracket xoay tự do và vòng xung nhịp laser.
- Tự động thay đổi kích thước, nội suy vị trí mượt mà (smooth lerp damping), kích hoạt sóng chấn động neon (**Cyber Shockwave**) khi click chuột.

### 🌓 4. Hệ thống Cyber Dark / Light Mode (FOUC-Free)
- Chuyển đổi giao diện thời gian thực với bảng màu Cyberpunk tương phản cao (Cyan Neon `#00f2fe`, Emerald `#10b981`, Deep Space `#060814`).
- Lưu trạng thái vào `localStorage` và áp dụng thẻ thuộc tính ngay trước khi DOM vẽ (loại bỏ hiện tượng giật sáng Flash of Unstyled Content).

### 📱 5. Thiết kế Adaptive Responsive Đa Thiết Bị
- Tối ưu hóa layout với **CSS Grid & Flexbox nâng cao**, hiển thị sắc nét trên mọi độ phân giải từ Mobile (360px), Tablet (768px), Laptop (1024px) đến màn hình 4K.
- Menu điều hướng Navigation Bar tự động co giãn với hiệu ứng Frosted Glass (Glassmorphism mờ kính 16px).

### ⚡ 6. Kiến Trúc Hướng Module Độc Lập
- Thư mục riêng biệt cho từng thành viên trong `/members/`, đảm bảo mã nguồn của mỗi cá nhân không bị xung đột.
- Tích hợp sẵn bộ khởi tạo `_template/` chuẩn hóa, giúp thành viên mới tích hợp bài làm chỉ trong vài phút.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ

### Cách 1: Chạy bằng Node.js Server (Khuyên dùng)
Dự án được trang bị sẵn tệp `server.js` hỗ trợ tự động gán header `no-cache`, đảm bảo việc chỉnh sửa code được phản ánh ngay lập tức trên trình duyệt:

1. Clone mã nguồn về máy:
   ```bash
   git clone https://github.com/NguyenThienKhangWork/Profio.git
   cd Profio
   ```
2. Khởi động server nội bộ:
   ```bash
   node server.js
   ```
3. Mở trình duyệt và truy cập:
   ```
   http://localhost:3000
   ```

### Cách 2: Sử dụng VS Code Live Server
1. Mở thư mục `profio` bằng Visual Studio Code.
2. Cài đặt tiện ích mở rộng **Live Server** (của tác giả Ritwick Dey).
3. Chuột phải vào tệp `index.html` và chọn **Open with Live Server**.

## ⚙️ Quy Trình Triển Khai GitHub Pages

Repository được cấu hình để triển khai tự động qua **GitHub Pages**:

1. Đẩy toàn bộ mã nguồn lên nhánh chính `main` của repository trên GitHub:
   ```bash
   git add .
   git commit -m "feat: complete Profio ecosystem with 5 active nodes and modernized UI"
   git push origin main
   ```
2. Truy cập vào **Settings** của repository trên GitHub (`https://github.com/NguyenThienKhangWork/Profio/settings/pages`).
3. Tại mục **Build and deployment**:
   - **Source:** Chọn `Deploy from a branch`.
   - **Branch:** Chọn nhánh `main` và thư mục `/ (root)`.
4. Bấm **Save** và chờ GitHub Actions hoàn tất quy trình đóng gói (khoảng 1 - 2 phút).
5. Liên kết xuất bản chính thức:
   ```
   https://nguyenthienkhangwork.github.io/Profio/
   ```
